# Сайт «Верни себе себя»

Статический лендинг. Экраны: «тебе не нужно становиться другой» → «тобой управляет состояние» → узнавание себя → что изменится → методология → автор → программа обучения (2 недели, набор до 20 сентября, старт 1 октября) → формат → цена. Все кнопки (класс `js-bot`) ведут в `@teacher_life_bot?start=site`, где идут запрос номера, оплата и доступ в канал.

Если API на другом домене (Render), в `index.html` перед скриптами задайте:

`window.LIFE_API = "https://ВАШ-СЕРВИС.onrender.com";`

Иначе запрос `/api/intent` идёт на тот же хост (удобно, если сайт отдаёт FastAPI).

### Цели для Яндекс.Директа

| Цель | Где | Ценность | Зачем |
| --- | --- | --- | --- |
| `view_offer` | доскролл до блока оплаты | 50 ₽ | просмотр оффера |
| `bot_started` | /start в боте | 150 ₽ | Telegram + запуск (не клик на сайте) |
| `show_phone` | «Показать номер» в боте | 1 000 ₽ | отдала контакт |
| `payment_started` | клик «Оплатить» в боте | 15 000 ₽ | сильное намерение |
| `payment_success` | ЮKassa succeeded | 50 000 ₽ | деньги + ecommerce |

В кампании оптимизируйте в итоге на `payment_success`; пока мало оплат — временно на `payment_started` или `show_phone`.

Включите **электронную коммерцию** в счётчике. На успехе уходит purchase на 50 000 ₽.

Включите **Measurement Protocol** и положите токен в `METRIKA_MP_TOKEN` на сервере — иначе цели из бота не доедут.
